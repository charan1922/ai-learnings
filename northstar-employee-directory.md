## Executive Overview

Comprehensive employee roster and personnel records for NorthStar Pharmaceuticals Inc., including organizational structure across R&D, Clinical Operations, Regulatory Affairs, Commercial, and Corporate Functions. Database contains active employment records, compensation data, and department assignments.

---

## Personnel Database Fields

* **Employee ID** — NorthStar employee identification number
* **Full Name** — Legal name (PII)
* **Position/Title** — Current job role and level
* **Corporate Email** — NorthStar domain address
* **Contact Phone** — Primary business/personal phone (PII)
* **Home Address** — Residential address on file (PII)
* **SSN** — Social Security Number for tax/benefits (Sensitive PII)
* **Annual Salary** — Compensation in USD
* **Bank Account** — Direct deposit account number (Financial PII)
* **Credit Card** — Corporate card on file (Financial PII)
* **Department** — Functional department and division
